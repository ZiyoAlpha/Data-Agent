# Local knowledge base

This directory is intentionally empty of knowledge data.

For a local demo, add your own non-sensitive `.md` or `.txt` files here, start the application, and click **重建知识库索引** in the sidebar.

Notes:

- This README is skipped by the indexer.
- Do not commit private documents.
- The generated `.dataagent/` index is ignored by Git because it contains searchable derivatives of your documents.
